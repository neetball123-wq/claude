AUDIO REFINER音質リファイナー

曲を通すだけで、圧縮で削られた高域を補い、奥行きと広がりを足します。再生しながら「原音」と「リファイン」を切り替えて聴き比べてください。

再生する音 デモ曲を準備しています…  

入ってくる音をその場でリファインします。処理そのものの遅れは 0 ms です。ハウリングを防ぐため、ヘッドホンで聴いてください。

ゲームの音を取り込む準備

Windows のゲーム

  1. 無料の仮想オーディオ「VB-CABLE」を入れる（vb-audio.com）
  2. 設定 → システム → サウンド → 音量ミキサーで、ゲームの出力デバイスを「CABLE Input」にする
  3. Chrome か Edge でこのページを開き「ゲーム・パソコンの音」を押す。出力はヘッドホンを選ぶ

Mac のゲーム

  1. 無料の仮想オーディオ「BlackHole 2ch」を入れる（existential.audio）
  2. システム設定 → サウンド → 出力を「BlackHole 2ch」にする
  3. Chrome でこのページを開き「ゲーム・パソコンの音」を押す。出力はヘッドホンを選ぶ

Switch・PS5・Xbox などのゲーム機

  1. キャプチャーボードか、オーディオインターフェースのライン入力でパソコンに音を入れる
  2. 「マイク・入力機器」を押し、入力にその機器を選ぶ

iPhone・Android のゲーム

  1. スマホの中では、ほかのアプリの音を加工できません
  2. イヤホン端子（変換アダプタ）からケーブルでパソコンの入力につなげば、パソコン側で処理できます

ブラウザで流している音

  1. パソコンの Chrome / Edge で「ブラウザのタブの音」を押し、共有画面で「タブの音声を共有」をオンにする

音ゲーなどタイミングが大事なゲームでは、入出力の遅れ（画面の「遅延」の値）が気になることがあります。

細かく調整

リファインした音を曲全体で書き出して保存します（16bit WAV）。長い曲は数十秒かかります。

処理の流れ

入力→高域補完→明瞭度 EQ→低域＋倍音→ステレオ幅→空間→迫力→リミッター

できること・できないこと

  • 使える音：端末に保存した MP3・AAC(m4a)・WAV・AIFF など。iPhoneでは「ファイル」アプリから選べます。
  • 高域補完は、残っている5kHz以上の成分から倍音を作り、MP3やAACで削られた16kHz以上を埋め直す処理です。失われた音を推定して作り直すもので、元の録音を完全に復元するものではありません。
  • 空間はヘッドホン・イヤホン向けです。スピーカーで聴いているような左右の回り込みと部屋の響きを加えます。iPhoneの空間オーディオのような、頭の向きに合わせた追従はしません。
  • Apple MusicやSpotifyで再生中の音には直接かけられません。iPhoneは他のアプリの音を加工する仕組みを公開していないためです。著作権保護（DRM）付きの曲も読み込めません。
  • ライブ入力は、マイク・入力機器（iPhoneでも可）、パソコンのゲームの音（仮想オーディオ経由）、ゲーム機の音（キャプチャーボード経由）、パソコンの Chrome / Edge で流しているタブの音に対応します。処理による遅れは 0 ms で、残りは端末の入出力の遅れです。Bluetooth イヤホンはそれ自体に 0.1〜0.2 秒ほどの遅れがあるので、遅延を最小にしたいときは有線をおすすめします。
  • ライブ入力は、マイクを使える通常の Web ページとして開いたときに動きます。Claude のプレビュー画面の中ではマイクや画面共有が使えません。
  • 最後にリミッターを通すので、設定を強めても音割れしません。
